# 语法参考

PyCN 沿用 Python 的语法结构，只把词汇换成中文。英文关键词同样可用，全角符号和半角符号也可以混用。

本页列出当前解析器实际支持的内容。想直接看可运行的代码，请前往[案例](./basic-usage.md#案例)。

## 语句

| PyCN | Python |
|------|--------|
| `定义 函数名（参数）：` | `def name(params):` |
| `类 类名：` / `类 类名（基类）：` | `class Name:` / `class Name(Base):` |
| `如果 条件：` / `要不然 条件：` / `否则：` | `if` / `elif` / `else` |
| `迭代 变量 在 可迭代对象：` | `for var in iterable:` |
| `返回 值` / `返回` | `return value` / `return` |
| `跳出` / `继续` / `过` | `break` / `continue` / `pass` |
| `导入 模块 作为 别名` | `import module as alias` |
| `从 模块 导入 名称 作为 别名` | `from module import name as alias` |
| `拉姆达 参数：表达式` | `lambda params: expression` |
| `@装饰器` / `装饰 装饰器` | `@decorator` |
| `变量 赋值为 值` | `variable = value` |
| `甲，乙 赋值为 乙，甲` | `a, b = b, a` |
| `对象.属性 赋值为 值` | `obj.attr = value` |
| `字典【键】赋值为 值` | `d[key] = value` |

函数参数支持用 `*参数` 表示 `*args`，用 `**键值对参数` 表示 `**kwargs`；普通参数保留中文名称。

```pycn
定义 求和（甲，乙，*参数，**键值对参数）：
    返回 甲 加 乙
```

## 标点与字面量

中文标点可以省略，同一个文件里也可以混用中英文标点。

| PyCN | Python |
|------|--------|
| `（` `）` | `(` `)` |
| `【` `】` | `[` `]` |
| `，` | `,` |
| `：` | `:` |
| `“…”` / `‘…’` | `"..."` / `'...'` |
| `《` `》` | 比较运算中的 `<` `>` |
| `！=` | `!=` |

花括号 `{` `}`、点号 `.` 和装饰器 `@` 仍需使用半角符号。

字面量沿用 Python 的模型：

- 数字可以用阿拉伯数字或中文数字书写：`十二`、`一百`、`零点一`、`负零点五`。
- 字符串可以使用英文引号或中文引号，`f` 字符串使用常见的 `f"..."` 形式。
- 列表使用 `【】`，字典和集合使用 `{}`，元组使用 `()`。
- `真`、`假`、`空` 分别对应 `True`、`False`、`None`。

```pycn
名字 赋值为 “张三”
成绩 赋值为 【九十，八十五，一百】
信息 赋值为 {"姓名": 名字, "成绩": 成绩}
打印（f"{名字} 的成绩是 {成绩【零】}"）
```

## 当前限制

- 暂不支持调用时使用关键字参数（`名称=值`）以及推导式。
- 尚未实现 `while`、`try` / `except`、`with`、`async` / `await`、`yield`、`match`、`raise`、`assert`、`del`、`global`、`nonlocal`。
- 多变量赋值的目标只能是普通名称；属性和索引需要逐个赋值。
- 本地 `.pycn` 模块按文件名在导入文件所在目录中解析，不支持点号分隔的模块路径。
